2-1_大模型咋就懂咱说啥_

发表于2026-05-25|更新于2026-05-25|Agent学习第02章 大白话快速简单过一遍 Ai 大模型
|浏览量:

1. 一句话定位

大模型把你的文字先拆成 Token、再变成向量，所有”懂语义”都发生在向量空间里。

摘要：取舍出现在 §2.4（把”星巴克”demo 从开场素材改成验证案例）；加工增量在 §3 与 §5（嵌入层来源 / 中文分词坑 / 知识地图均不在 understanding.md 出现）。

2. 主体讲解

2.1 先把骨架钉死：大模型只做三件事

你可以把任何一次和 DeepSeek 的对话想成一条流水线：

  1. 用户输入（Prompt） —— 你打的那句话
  2. 大模型计算 —— 在向量空间里做几何运算
  3. 大模型输出 —— 把结果再翻译回人话

这集只把第 1 步拆透，第 2、3 步留给后面几集。所以如果你看完本集还不知道 Transformer 是啥，是正常的——这集压根没讲。

2.2 输入这一段又分两步：分词 → 向量化

输入侧再放大，会发现里面藏着两小步：

  • 分词（Tokenization）：把你那句话切成最小处理单位，标点也算一个 Token。
  • 向量化（Embedding）：把每个 Token 通过”嵌入层”映射成一串数字（向量）。

记住一个区分：Token 有个唯一 ID（像学号），但 ID 不是向量；向量是 ID 再经过嵌入层之后那一长串能”刻画特征”的浮点数。这两者新手很容易混。

2.3 为啥非得是”向量”，不是”编号”

这是这集最该带走的直觉。两个理由：

  1. 计算机只认数字。文字、图片、声音都得先变成数字才能算。这是底层硬约束。
  2. 关键是”哪种数字”。如果只给 Token 一个流水号，那”猫”和”狗”对模型来说就跟”3 号”和”7 号”一样——除了不相等，啥关系也没有。但如果把”猫”变成 (灵活, 吃老鼠, 吃鱼, …)、把”狗”变成 (忠心, 吃骨头, 看门, …)，那模型就能用几何距离判断它们是不是同类。

换句话说：向量化的真正魔法是把”语义相似”变成”距离相近”。维度越多，刻画得越细。

2.4 向量空间：一切推理的舞台

把世间万物都塞进同一个高维空间，每个东西在里面占一个唯一的点，这就是向量空间。这集留下一句很重的话：

大模型所有的推理计算，都是在向量空间里进行的。

记牢这句，它会在后续 3-1（大模型困境）那集被反复用来论证”为什么模型回答不了实时问题”。

2.5 回头看”星巴克”demo，为啥能”懂”

取舍点：原视频用两个”星巴克”问题作为开场抓眼球；这里我故意挪到最后做验证案例，避免你误以为这集讲的是”指代消解算法”。

两个问题：

  • A：”我在咖啡馆里想要杯星巴克” → DeepSeek 答：你想要的是咖啡饮品
  • B：”看到别人拿着星巴克，我也想要个” → DeepSeek 答：你想要的是星巴克的杯子

同样的三个字”星巴克”，为啥能区分出”咖啡”和”杯子”？

因为分词后那个”星巴克”Token 进入嵌入层后，会和上下文 Token 一起被映射到向量空间里的不同位置——A 句里它落在”咖啡饮品”区域附近，B 句里它落在”实物 / 周边商品”区域附近。

注意：本集只让你接受这个结论，没解释”上下文怎么影响向量位置”——那是注意力机制 / Transformer 的活儿，留给 2-2、2-3。

3. 我一开始没 get 的点 / 容易踩的坑

  1. Token ID ≠ 向量。Token ID 只是个流水号（”星巴克” = 12345），向量是这个 ID 再过一层”嵌入层”之后那串”带特征”的数字。混了这两个，后面 attention 的 Q/K/V 全看不懂。
  2. “向量化”不是模型的核心魔法，它只是个入口。本集把它放在”输入阶段第 2 步”，真正的推理在向量空间里展开。别一听”Embedding”就以为是高级法术——它只是把字塞进可计算的格子。
  3. 嵌入层的参数从哪来？（understanding.md 也留了这个坑）—— 嵌入层本身是训练出来的：模型在大量语料上反复调参，让”语义相近的词在空间里也相近”。视频没讲这点，但你心里得知道这一层不是手写规则，是学出来的。
  4. 中文分词不是”按汉字切”。视频用”在咖啡馆里想要杯星巴克”做例子，含糊带过了切分细节。实际大模型常用 BPE / WordPiece 这类子词算法，”星巴克”在不同 tokenizer 里可能是 1 个 Token、也可能被切成 3 个字。本集没讲，等遇到 token 计费再回头补。

6. 自测题

Q1：大模型的工作流程被分成哪三段？这集重点讲的是哪一段？

A用户输入 → 大模型计算 → 大模型输出；本集只展开了第 1 段"用户输入"，分到分词和向量化两小步。

Q2：Token ID 和向量是同一个东西吗？

A不是。Token ID 是分词后给每个 Token 的唯一编号（像学号），向量是这个 ID 再经过嵌入层后映射出的一串带语义特征的数字。

Q3：为什么要把词变成向量而不是简单地编号？

A编号只能表达"相等 / 不等"。向量的每一维代表一个特征，于是"语义相似"可以转化为"几何距离接近"，让大模型能用数学方式比较和推理语义。

Q4：同样三个字”星巴克”，DeepSeek 为什么能在两个句子里分别推断为”咖啡”和”杯子”？

A因为嵌入层会把 Token 连同上下文一起映射到向量空间中的不同位置——A 句里靠近"咖啡饮品"区，B 句里靠近"实物商品"区。本集只给结论，原理留给注意力机制那几集。

Q5：向量的维度越多代表什么？

A刻画的特征越多、对该对象的描述越具体。在向量空间里它的位置也越独特，越不容易和其它对象混淆。

7. 关键词表

术语 一句话
大模型三段式 用户输入 → 大模型计算 → 大模型输出，本集只展开第 1 段
Prompt 用户敲进去的那句话，整条流水线的起点
分词 Tokenization 把 Prompt 切成最小处理单位的过程，标点也算一个
Token 分词后的最小单位，每个有唯一 ID
Embedding 嵌入层 把 Token ID 映射成高维向量的那一层网络，参数是训练出来的
向量 一串带特征的数字，每一维刻画对象的一个突出特征
向量空间 所有向量栖身的高维空间，大模型的全部推理都在这里完成
上下文相关语义 同一 Token 在不同 Prompt 中落到向量空间不同区域，因此能区分语义
