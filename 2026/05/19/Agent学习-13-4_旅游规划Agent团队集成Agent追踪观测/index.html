13-04 旅游规划Agent团队集成Agent追踪观测

1. 一句话定位

把上一节装好的 Langfuse 后台接到旅游规划工程里——pom 加桥包 → .env + yml 喂参数 → LangFuseUtils.initLangfuseTracing() 造 TelemetryTracer 注册到全局，之后 Agent 跑起来自动上报，业务代码一行不动。

2.4 注册到全局：ManagerRegion 一锤定音

📺 04:33–06:00 · IDE 中在 ManagerRegion 注入并注册 Tracer

在主管 agent 模块的 ManagerRegion（智能体创建/运行入口）注入 LangFuseUtils，拿到 initLangfuseTracing() 返回的 TelemetryTracer，把它注册到全局跟踪对象。

然后呢？

老师原话：”接着叫做什么——什么都不用做了。”

这是本集的关键加工点——一次注册，下游所有 Agent 调用都被全局 Tracer 自动拦截上报，业务代码零侵入。Spring AI 的 observation 扩展走的是 OpenTelemetry 标准，TelemetryTracer 在底层是 OTel Tracer 的实现，能力体现在 SPI/拦截器，不在每个 Agent 显式埋点。

3. 没 get 的点

  • “注册到全局跟踪对象” 对应的 API 视频没给——是 AgentScope 的某个静态注册器（AgentScopeContext.setTracer(...)?）还是 Spring 容器的 TracerProvider Bean？要进 ManagerRegion 源码看。
  • 三个子 agent（manager / routeMaking / tripPlanner）是否都要重复一份 yml + utils？视频只演示 manager。推测：commons 模块的 utils 是共享的，但每个 agent 模块都要有自己的 yml 引用同样的 .env，因为它们各自独立启动；具体三选一谁负责注册全局，待后续集确认。
  • 采样 < 1 时跨 agent trace 的父子绑定策略——OTel 默认是父决定子，但本工程是否启用 ParentBased Sampler 不明。
  • yml 的 key 路径 spring.ai.observation.langfuse.* 是 SAA 桥包自定义的，不在 Spring AI 官方 schema 里——意味着 IDE 黄色波浪线提示是正常的。

5. 知识地图

6. 自测题（5 卡）

  1. Q：为什么项目里见到的是 TelemetryTracer 而不是 LangfuseClient？
    A：接入走的是 spring-ai-alibaba-observation-extension 这个桥包，它把 OpenTelemetry 标准的 Tracer 数据吐给 Langfuse 兼容端点。Langfuse 这边只暴露 HTTP 接口，所以客户端是通用的 OTel Tracer，鉴权用标准 HTTP Basic。

  2. Q：getAuthHeader() 里为什么是 publicKey + ":" + secretKey 这个顺序？反过来行不行？
    A：标准 HTTP Basic 格式是 username:password，Langfuse 约定 publicKey 当用户名、secretKey 当密码——反过来 401。base64 编码后前缀必须是 "Basic "（带空格）。

  3. Q：sampling-rate: 1.0 上生产意味着什么？怎么改？
    A：意味着 100% 采样，所有 trace 都上报——后台存储和带宽压力大、可能拖慢主链路。生产建议 0.1–0.5（10%–50%），改 yml 重启即可；调试某个具体问题时临时拉满。

  4. Q：”业务零侵入”是怎么做到的？关键动作是哪一步？
    A：在 ManagerRegion 把 TelemetryTracer 一次注册到全局跟踪对象。之后 SAA 的 observation 扩展通过 SPI/AOP 拦截所有 Agent 调用自动埋点，业务代码不需要任何 tracer.startSpan() 之类的显式调用。

  5. Q：如果启动报”无法解析 ${LANGFUSE_ADDR}“，先查哪三处？
    A：① .env 文件名/位置（必须在根目录，且 yml 里 spring.config.import: optional:file:.env[.properties] 已声明）；② key 拼写——截图 OCR 里实际是 LANGFUSE_ADDRE，要和 yml 里 ${LANGFUSE_ADDR} 对齐；③ Properties Bean 上的 @Value 路径是否与 yml 嵌套层级一致（spring.ai.observation.langfuse.endpoint）。
