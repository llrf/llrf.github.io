9-01 AgentScope搭建工程化的分布式Agent协同

发表于2026-05-19|更新于2026-05-21|Agent学习第09章 Docker 部署分布式 Agent 搞定旅游规划
|浏览量:

1. 一句话定位

这集是第 9 章的纲领图：多 Agent 协同的”自主代理派”里，你把主角从 JManus 切换到 AgentScope，理由是它把六件能力直接做成了工业级工程化（Docker / 多 ReActAgent / MCP 节点 / Skills / Subagent / A2A+Nacos），后续旅游规划实战就靠它。

2. 主体

先把分叉理清

⏱ 00:00–01:38 · 工作流编排 vs 自主代理两派分叉

多 Agent 协同前面分了两派，你要记得自己站在哪个位置：

  • 工作流编排派：人工设计流程。底下又两路——Graph 引擎（StateGraph / OverAllState）和 SAA 1.1 的 FlowAgent（Parallel / Routing / Sequential）。这条线 7-13 已经收尾。
  • 自主代理派：让 Agent 自己决定流程怎么走，本集就开始走这条。

自主代理派的两个落地框架，f001 那张总览图画得很清楚：

⏱ 00:00

  • JManus（Java 版 Manus）—— 被讲师明确划成”非重点”。
  • AgentScope（重点，企业级、工程化）—— 基于 Spring AI Alibaba 1.1。

加工增量：前面 8-9 到 8-13 整整 5 集都在拆 JManus 源码，到这集突然降级，课程视角发生了切换——前面是”读懂自研版本”，从这集起转向”用工业级 SDK”。别再纠结 JManus 那套实现细节，它的角色变成了”对照样本”。

为什么是 AgentScope：六件套

⏱ 01:38–03:30 · 引出企业级工程化六件能力栈

讲师反复说”企业级、工程化”，但定义晚——直到 138s 那张图把六个点列出来你才知道指的是什么：

⏱ 02:18

把这六件按”部署 → 执行 → 工具 → 协作”四档归一下：

档位 能力 干什么
部署 Docker 分布式 Agent 不同角色 Agent 跑在不同节点上
执行 多 ReActAgent 协同 整体计划层做任务分解派单 + 单任务层走思考-行动-反思
工具 MCP 服务部署为单独节点 MCP 不是嵌进 Agent 进程，而是独立服务节点
工具 Skills 工程化 把 3-7 那集的 Agent Skills 概念产品化
协作 Subagent 固定化子任务独立分配一个子 Agent，独立上下文执行
协作 A2A 协议 + Nacos 分布式节点间的服务发现

多 ReActAgent 是两层，不是一层

⏱ 02:25–03:30 · 区分整体计划层与单任务层

容易踩的坑：以为”ReActAgent = 单 Agent 思考-行动-反思循环”，所以多 ReActAgent 协同就是一堆 ReAct 并排。错，AgentScope 里它是两层：

  • 整体计划层：把复杂任务拆开，分配给各个子 Agent。这层做”派单”。
  • 单任务层：每个被派到任务的 Agent，在自己内部走 ReAct 循环——先思考、再行动、再反思，目标没达到就回去修正行动。

加工增量：ReAct 在这张总览里同时占两个位置——左上”自主思考”分支挂着 ReAct 思维框架（概念定义），右侧 AgentScope 里又挂”多 ReActAgent 协同”（执行单元）。同一个 ReAct，既是单 Agent 的内循环、又是多 Agent 的执行单元，别看花眼。

Subagent ≠ MCP 单节点

⏱ 03:30–04:30 · 拆开 MCP 节点和 Subagent 两种隔离

听讲师讲两段都像”独立运行”，要分清：

  • MCP 单节点：工具服务的工程化部署，让 MCP 不再嵌在 Agent 进程里，独立成服务。这是部署粒度上的隔离。
  • Subagent：任务上下文的隔离。一个固定化的子任务，开一个子 Agent，在独立上下文里跑完，不污染主执行计划的上下文。这是 Agentic AI 的关键能力之一。

A2A 这里指什么

⏱ 04:30–04:55 · A2A 在本集的服务发现角色

A2A 在 3-10 那集是”跨部门协作通信协议”，本集换了个角度——服务发现：分布式部署后，各节点上的 Agent 互相不知道谁存在，要靠注册中心（这里用 Nacos）来发现。AgentScope 把这套封装好了，几行配置就能跑。

全部为了一件事：旅游规划

⏱ 04:55–05:07 · 收束到旅游规划实战目标

这六件工程化能力都不是空中楼阁，最后落到课程后续的项目实战：旅游规划。
