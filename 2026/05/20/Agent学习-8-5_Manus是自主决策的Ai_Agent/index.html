8-5_Manus是自主决策的Ai_Agent

发表于2026-05-20|更新于2026-05-20|Agent学习第8章 Jmanus 懂思考、会规划、一步步动手完成任务。
|浏览量:

1. 一句话定位

把 8-4 那张”规划-分发 + 单 Agent 执行”的两条骨架，各自挂一根反馈闭环，Manus 的第三大特点（自主决策）就成型了——人只下需求，剩下全自转。

2. 主体

2.1 先把”为什么 Manus 当年炸场”摆清楚

讲师在这集开头复盘了 Manus 的三大特点，你需要把它们看成叠加增益而不是平行清单：

  1. 多智能体协同——8-4 讲过的拆解 / 分发。
  2. 能用外部工具——MCP 调用浏览器、本地 DB、第三方 API。这一条把”对话机器人”升级成了生产力。
  3. 自主决策（本集主角）——制定计划 → 执行 → 反思修正，全程没有人。

加工增量：消化稿原本把第 3 条概括成”独立自主思考”，但讲师视频里反复强调一个隐含点——“自主决策”不是单点能力，而是给前两个骨架各加一条反馈边。所以这一集真正的新东西只有一个动作：给骨架加闭环。

2.2 两条骨架 + 两个自循环（图当锚）

f010（t=516s 的总结图）是这一集的终态全景：

第一个自循环 · 规划模块（计划级）

发生在 8-4 那个任务规划器里：

  • 思考计划 → 计划列表 → 执行计划 → 反馈问题：这是直线段，对应 8-4 讲过的”主管拆任务、调度器派单”。
  • 反馈 → 调整计划 → 回到计划列表：这是新加的反馈边。每完成一个子任务，Manus 都会反思这个子任务的完成情况，决定要不要动态改后面的计划。
  • 全部子任务跑完才走到”问题终点”。

加工增量：消化稿把这条闭环叫”子任务完成度反思”，比讲师”计划反思”更准——反思的颗粒不是”整个计划”，而是单个子任务完成后的回看。这是计划级反思和步骤级反思的关键分界。

第二个自循环 · 执行模块（步骤级）

发生在单个智能体内部：

  • 思考 → 行动 → 观察 → 循环执行：这是经典的 ReAct 三件套（视频里没点名，但流程一字不差）。
  • 拿到子任务后，单 Agent 自己排步骤：第 1 步做什么、第 2 步做什么……每跑一步都把结果”观察”一次，反馈回大脑，决定要不要改后面的步骤。

取舍标注：讲师在视频里把”步骤”和”计划”反复混用，听感很乱。记住一刀切：子任务之间的反思叫”调整计划”（规划模块的事），子任务之内的步骤反思叫”调整步骤”（执行模块的事）。两层都有反思，粒度不同。

2.3 两个”反馈”是两件事

“反馈”在 Manus 里指代两个独立机制，别混：

反馈类型 触发时机 反馈对象 后果
子任务级 每个子任务完成 规划器（计划级） 可能改后续子任务
步骤级 每个步骤执行完 单 Agent 大脑（步骤级） 可能改后续步骤

2.4 全链路无人介入

讲师在结尾给了一段长清单——你看完后会发现，人只在”提需求”那一刻出现，之后所有动作都没有人：

需求理解 → 任务拆解 → 任务分发 → 子任务反思调整 → 步骤执行 → 工具调用 → 步骤反思 → 步骤调整 → 多子任务结果汇总 → 友好输出

这条链路就是 Manus 当年炸场的全部理由：生产力（能调工具） + 自主决策（不用催） = 你心里那种”真 AI”。

3. 没 get 的点

  • “调整计划”具体由谁触发？——是任务规划器复用调一次自己，还是任务执行调度器自带反馈引擎？讲师只画了一根反馈箭头，没说箭头的源端是哪个模块。
  • 步骤反思 vs 工具调用失败重试——是同一回事吗？还是反思层高一级？比如工具超时该走重试机制还是走反思机制？
  • ReAct 这个术语——本集没点名，但流程就是 ReAct。要回去看 6-6 ReactAgent 那一节查命名出处。
  • “调整计划”是不是独立模块——还是规划器读到反馈后重跑一次思考？回去看 OpenManus 源码能验证。

4. 跟其他集的连接

  • 上承：3-12 多Agent核心执行流程 给了”多Agent五步骨架 + 单Agent五步循环 + 骨架嵌套”——本集就是给那两层骨架各加一条反馈边，正式升级为 Manus 的”两个自循环”。8-4（同章上一集）讲的任务规划器 / 调度器 / 隔离容器，就是本集”规划模块”的实体。
  • 下启：自主决策的代码落地在 6-6 ReactAgent.builder()——.saver() 存的就是反思状态，OutputType 四种事件流就是”思考/行动/观察”的事件化。再往后 7-12 基于Graph搭建旅游规划工作流 用 addConditionalEdges 把”调整计划”那条反馈边落成代码。
  • 横向：和 5-5 Agent团队和大模型的无缝协作 是同一张图的两个抽象层——5-5 是”主管+专科+汇总”的人力组织视角，本集是”规划循环+执行循环”的控制流视角。和 3-7 Agent Skills 互补：那集解决”工具怎么挂”，本集解决”工具调用之间怎么反思”。

5. 知识地图

6. 自测题（5 卡）

  1. Manus 两个自循环分别发生在哪一层？各自的反思颗粒是什么？
  2. 计划级反馈和步骤级反馈，触发时机有什么区别？反馈对象分别是谁？
  3. “调整计划”这条反馈边为什么不是每跑完整张计划才触发一次，而是每个子任务完成就触发？
  4. 单 Agent 内部那个”思考-行动-观察”循环，对应哪个经典 Agent 范式？
  5. 如果让你把 Manus 的”全链路无人介入”压成一句话，”人”在这条链路里的唯一位置是什么？
