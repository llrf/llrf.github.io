学习笔记 · 3-1 大模型困境：数据获取与整合上的”抓瞎”

来源：慕课网 imooc.com，视频 3-1 大模型困境：数据获取与整合上 的"抓瞎".mp4（约 7 分钟）
本笔记基于自动化 pipeline：whisper 转录 + scenedetect 关键帧 + PaddleOCR + Claude 多模态读图。原始产物：transcript.txt / frame_index.json / frames/。

一、本集主旨

承接上一章对 Transformer 架构的科普，本集话锋一转：从「大模型有多神奇」切入，最终引出大模型的两大致命缺陷——这是后续章节引入 RAG / 工具调用 / Agent 的动机。

二、回顾：上一章的 Transformer “三层结构”

讲师先用 0~9 秒回顾了上一章的整体架构图：

PPT 把大模型抽象成自下而上三层：

层 颜色框 含义
1. 用户输入 蓝色 用户的 Prompt 文本
2. 大模型计算 黄色 Transformer 层（堆叠的粉色卡片表示多层结构）
3. 大模型输出 粉色 模型返回的回答

红色箭头自下而上贯穿，表示信息流方向。

三、本集的”标准 Q&A 流程图”（贯穿全集的视觉模板）

讲师从 18 秒起换到一张核心流程图，本集所有反例都基于它演化：

结构：

  • 顶部：用户头像
  • 用户向下发送：「输入 (Prompt)」
  • 进入：LLM 大脑图标（带神经网络节点）
  • 内部环节：「语义分析」
  • 完成后：「返回」箭头沿左侧向上回到用户

这是一个理想闭环：用户问→ LLM 分析→返回。本集后面要讲的两个”抓瞎”反例，本质都是这个闭环被打破。

四、铺垫：大模型的三大”神奇”

视频前半段先把读者期待拉满，列举三个让 LLM 看似通用智能的现象：

# 神奇之处 举例
1 知识面极广：精通古今中外、天文地理、历史文化 问《红楼梦》某角色 → 性格、结局、出现章节都能答；问法国某幅名画 → 作者、馆藏地、影响
2 能推理用户意图 “在咖啡馆里想要杯星巴克” → 能从语境推断”星巴克”指饮料而非品牌或店面
3 能按用户习惯返回 让它”以广东人的方式回答” → 能用地道的广东俚语作答

目的：让你以为 LLM 完美无瑕，再用下面的反例打破滤镜。

五、反例 1：今天深圳的气温是多少度？

讲师在 PPT 里直接把这个 Prompt 喂进了流程图：

注意这张图的信息架构——它把上面的”标准闭环”做了两处变化：

  1. 用户右侧弹出 Prompt 气泡：「Prompt：今天气温多少度？」，箭头插入到 LLM 的语义分析里
  2. 流程图底部新增了红色横幅：「糟糕，模型训练的数据并没有当天的数据」

视觉表达极其直接：闭环没有”返回”了——LLM 卡在 语义分析 这一步，因为知识库里没有今天的气温数据。

六、反例 2：把公司客户订单整理成季度销售报告

讲师把同一张 PPT 模板换了 Prompt 内容：

反例 Prompt 内容
1 “今天气温多少度？”
2 “根据客户订单生成季度销售报告”

视觉与反例 1 同构，只是 Prompt 内容换成了”私域数据请求”。这是同构的反例——用同一张图讲两类完全不同的失败。

七、核心原理：为什么 LLM 答不上来？

7.1 大模型运算的本质——向量空间

回顾上一章的关键论点（也是本集的论证基础）：

  • 训练时，所有语料（如整本《红楼梦》）被转换为向量喂给模型
  • 在 LLM 的向量空间里，每个事物（人、物、事件）对应唯一的一个点
  • 这个点（向量）由上百、上千、上万个参数构成，编码它的突出特征
  • 红楼梦里所有人物在向量空间里都有各自唯一的一个点，点与点之间的距离 / 方向勾画出人物间的关系
  • LLM 回答问题，本质就是在向量空间内做数学运算（找邻近、算概率）

7.2 推理用户意图，本质也是向量距离

  • LLM 从用户输入中提取关键词
  • 看这些关键词在向量空间里靠近哪些物品 / 事件
  • 概率最高的关联即被推断为用户意图

例：「咖啡馆 + 星巴克」→ 向量空间里离”咖啡饮料”最近 → 推断意图为饮料而非品牌。

7.3 关键论断（本集的”题眼”）

如果向量空间里没有唯一的点指代某个事物，LLM 就根本推理不出来。

这是判断 LLM 能不能回答某类问题的唯一判据。

7.4 用论断解释两个反例

反例 为什么答不上来
深圳当前气温 这是一个实时变化的数值，从来没作为训练数据进入过模型，向量空间里没有任何一个向量指代”此刻的深圳气温”
公司客户订单 这是私有数据，模型训练时根本接触不到，向量空间里没有任何一个向量指代这些订单

八、本集结论：大模型的两大致命缺陷

讲师用两张统一风格的总结幻灯给出结论——把前面的失败流程图变暗作为背景，再把一个亮色横幅叠加在中央，强化”这是核心结论”的视觉冲击。

缺陷 1：无法获取时效性数据

  • 黄色高亮横幅：「无法获取 时效性的问题」
  • 背景：变暗的反例 1 流程图（”Prompt：今天气温多少度？” + “糟糕，模型训练的数据并没有当天的数据”）
  • 画面左下角隐约可见**「调用外部 API」字样——讲师在此预告**：这就是后续章节要讲的解法之一

缺陷 2：无法拥有用户私有数据

  • 红色高亮方框：「无法拥有 用户的私人数据」
  • 背景：变暗的反例 2 流程图（”Prompt：根据客户订单生成季度销售报告” + “糟糕，模型训练的数据并没有客户订单数据”）

标题里的”抓瞎”指的就是这两件事——在数据获取和数据整合上，LLM 一片空白。

九、知识地图（一图速记）

十、关键词表

术语 含义
向量空间 LLM 内部把所有概念、词、事物表示为高维向量的几何空间
向量 一组（百到万级）参数构成的数组，编码事物的语义特征
时效性数据 随时间变化的数据，如天气、股价、新闻——训练后才发生的事都属于这类
私人 / 私域数据 不在公开互联网上、企业或个人内部的数据，如订单、内部文档
语义分析 LLM 内部理解 Prompt 含义的环节（讲师 PPT 用此名指代 LLM 推理过程）
Prompt 用户输入的提示词；本集 PPT 反复用 Prompt：xxx 句式举例

十一、思考题（自测）

  1. 如果我问 LLM「2025 年的诺贝尔化学奖是谁」，它一定答得上来吗？为什么？
  2. 假设你把公司订单整本喂给 LLM 做”上下文输入”，它能回答订单相关问题吗？这和”训练”有何区别？
  3. “向量空间里没有这个点”是绝对的吗？有没有办法临时让模型获得某条信息？
  4. PPT 在缺陷 1 的总结页底部隐约写了「调用外部 API」——你认为这是怎么做到的？（提示：思考 LLM 与”工具”如何配合）
