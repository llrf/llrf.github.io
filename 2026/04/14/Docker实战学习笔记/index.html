1. Docker 核心概念

学习 Docker 之前，必须理解三个核心概念：镜像、容器、仓库。

概念 类比 说明
镜像（Image） 面向对象中的 class 应用程序的只读模板，包含运行所需的一切（代码、依赖、环境）
容器（Container） 面向对象中的 对象 镜像的运行实例，可启动、停止、删除
仓库（Repository） 代码仓库 存储和分发镜像的地方，如 Docker Hub
Dockerfile 构建脚本 定义镜像构建步骤的脚本

核心理解：把镜像理解为”食谱”，容器理解为”做出来的菜”——食谱可以复用，菜做了就没了。

4. docker run 详解

docker run 是最核心的命令，用于创建并启动容器。

4.1 基础用法

4.2 常用参数一览

参数 说明 示例
-d 后台运行容器（detached） docker run -d nginx
-p 端口映射（宿主机:容器） docker run -p 8080:80 nginx
-v 目录挂载（宿主机:容器） docker run -v /data:/data nginx
--name 指定容器名称 docker run --name my-nginx nginx
-it 交互式终端（-i + -t） docker run -it ubuntu bash
--rm 容器退出后自动删除 docker run --rm ubuntu sleep 10
-e 设置环境变量 docker run -e MYSQL_ROOT_PASSWORD=123456 mysql
--network 指定加入的网络 docker run --network my-net nginx

6. Docker 网络

6.1 网络模式一览

Docker 提供多种网络模式，适合不同场景：

模式 说明 适用场景
bridge 默认模式，容器连接到一个虚拟网桥 单机容器互联
host 容器直接使用宿主机网络 高性能场景
none 容器无网络连接 离线任务
overlay 跨主机容器通信 Docker Swarm 集群
自定义子网 用户创建的专用网络 生产环境隔离

默认 bridge 网络：容器之间通过 IP 地址互相通信，但如果容器重启，IP 可能变化。

7. Docker Compose 容器编排

7.1 什么是 Docker Compose

Docker Compose 是轻量级的容器编排工具，通过 docker-compose.yml 文件定义多容器应用，实现”一键启动整套应用”。

使用场景：比如一个 Web 应用需要 Nginx（前端）、Node.js（后端 API）、MySQL（数据库），用 Compose 可以一个命令全部启动。

总结

Docker 是现代 DevOps 和云原生开发的基础，掌握以下核心即可应付日常开发：

  1. 镜像操作 — pull、images、rmi
  2. 容器操作 — run、ps、stop、rm、logs、exec
  3. 网络模式 — bridge（默认）、自定义子网
  4. 数据持久化 — -v 挂载数据卷
  5. 容器编排 — docker-compose.yml 管理多容器应用
